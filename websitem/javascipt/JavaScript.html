Javascript Nedir

Javascript html sayfaları ile birlikte kullanılan kodlama dilidir. HTML nin yetersiz kaldığı durumlarda kodla işlem yapılmak istendiğinde kullanılabilir.

JS yazım şekilleri

  • İnline (satir ici) kod yazımı. - Bu maddeye tıklayınız.
  • internal (sayfa ici-head)-tıklayınız
  • External (harici .js dosyasından kod cagirisi) bu kod site.js de yazıldı ve oradan cagirildi -tıklayınız

Output - çıktı

  • alert('mesaj'); - alert komutu pop-up mesaj çıktısı üretir.
  • document.write('ifade'); - bodyye mesaj yazar.
  • console.log('ifade'); - developer tools içindeki konsol ekranına bilgi yazmak içiin kullanılır genellikle geliştirme aşamasında kullanılır. konsol ekranını kontrol ediniz
  • sayfa içindeki bir elemente içerik basmak.

Input - girdi

  • prompt('mesaj','default deger') komutu ilr değer almak için Tıkla
  • sayfa içindeki bir elementin değerini almak.
